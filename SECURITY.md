# Security Policy

## Supported Versions

We actively support the latest minor release of `spicetify-connect-api` with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

---

## Reporting a Vulnerability

We take security issues in `spicetify-connect-api` seriously. If you discover a security vulnerability, please **do not** create a public GitHub issue.

### How to report:
1. **GitHub Security Advisory (Preferred):** Report privately via [GitHub Security Advisories](https://github.com/tobfd/spicetify-connect-api/security/advisories/new).
2. **Email:** Send a report directly to **support@tobfd.de**.

### What to include in your report:
* A description of the vulnerability and its potential impact.
* Clear steps or a minimal proof-of-concept script to reproduce the issue.
* Any suggested remediations (if available).

### What to expect:
* **Acknowledgment:** Within 48 hours of receiving your report.
* **Updates:** Periodic updates on progress toward a resolution.
* **Credit:** Once a security patch is released, we will credit you in the release notes (unless you prefer to remain anonymous).
